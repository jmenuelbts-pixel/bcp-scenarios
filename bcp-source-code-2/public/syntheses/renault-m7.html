MISSION 7 Conclure la vente et financer le crédit
Les signaux d'achat Indices qui montrent le bon moment pour conclure
Signaux verbaux positifs Le client se projette dans l'avenir, demande des détails
Le client critique tout, ne voit que le négatif, émet des objections prétextes
Le client sourit, est détendu, avance vers le bureau
Signaux non verbaux négatifs Le client reste silencieux, se gratte la tête, s'enfonce dans sa chaise
Rôle des signaux Repérer le moment de lancer la conclusion
Les techniques de conclusion Inciter le client à se décider
Inviter naturellement le client à finaliser (« Alors vous la prenez ? »)
Proposer un choix entre deux solutions (« essence ou diesel ? »)
Apporter un argument gardé de côté pour précipiter la décision
Le reste à vivre et l'endettement Vérifier la capacité du foyer à emprunter
Somme restante une fois toutes les charges payées : rentrées d'argent moins dépenses
Taux d'endettement Dépenses du ménage / salaires du couple x 100
Seuil d'endettement 33 % maximum, au-delà le crédit est refusé
Le coût du crédit Ce que l'achat coûte réellement au client
Intérêts à payer (mensualité x 12 x nombre d'années) moins le prix du véhicule
Aide déduite du prix pour l'achat d'un véhicule plus propre
